# 复现手册（交给队友 / 其他同学）

> 目标：换一台 Windows 电脑，**不解压任何额外东西、不改一行代码**，30 分钟内跑出与本机一致的产物和界面。
> 本文档只讲"给什么、怎么跑、跑不对怎么办"；方案本身见 `方案设计/技术方案与实施指引.md`。

---

## 0. 先划清共享边界（重要）

| 对象 | 能给什么 | 不能给什么 |
|---|---|---|
| **本队队友** | 全部代码 + 全部数据 + 全部产物 | —（队内共享不受限） |

| 任何人 | — | `api.txt`（含真实 Key）、任何真实学生信息 |

赛题原文："赛题组提供的课程标准、学情数据等资料仅限本次大赛使用，不得外传或用于其他用途，赛后须按赛题组要求删除。"
→ 所以外发版本请用 **§2 的"代码版"清单**，并在 README 顶部保留这句话。

## 1. 队友拿到后 3 步跑通

```powershell
# ① 准备环境（自动建 .venv-ui + 装依赖 + 自检）
.\scripts\bootstrap.ps1 -Python "D:\python313\python.exe"

# ② 一键跑完 01–03、06（05 需 pyvis、04 需向量库，缺依赖会自动跳过）
.\scripts\run_all.ps1

# ③ 启动界面
cd ui ; .\run.bat
```

预期：`run_all.ps1` 最后打印 `[OK] 产物齐全且关键数字一致`；浏览器打开 `http://localhost:8501`。

## 3. 为了让别人能跑，已经做了什么调整

| # | 调整 | 原来 | 现在 |
|---|---|---|---|
| 1 | **路径可移植** | 6 个脚本写死 `D:/学习资料/AI竞赛/工作区/output` | `os.environ.get("SS_OUT") or <脚本目录>/../output`；01 的 `DATA_DIR` 同理支持 `SS_DATA` |
| 2 | 数据相对定位 | 写死赛题数据绝对路径 | 默认按工程相对位置推导，移动整个文件夹不影响 |
| 3 | 一键环境 | 手工 pip，中文路径会崩 | `bootstrap.ps1` 自动选 ≥3.10 解释器、把 `TEMP` 指到 ASCII 目录、装完即自检 |
| 4 | 一键执行 | 要按顺序手敲 6 条命令 | `run_all.ps1` 串行执行 + 计时 + 自动校验，04 可 `-WithRag` 选开 |
| 5 | 产物校验 | 无 | `verify.py`：7 个必产文件 + 5 个关键数字（790/40/385/9/57.9%） |
| 6 | 界面启动 | 直接 `streamlit run` 报 `WinError 5` 并卡在 `Email:` | `ui/run.bat` / `run.ps1` 自动重定向 `HOME` 到 `.streamlit-home` 并预写 `credentials.toml` |
| 7 | 依赖版本 | 只有口头清单 | `requirements.txt` 全部**锁定版本**（Streamlit 1.67 / Plotly 7.1 / pandas 3.1.1 / openai 3.51） |
| 8 | 缺依赖的降级 | 04/05 直接崩 | 05 缺 `pyvis`、04 缺 `chromadb` 时会打印"缺少依赖"并跳过，不影响其余步骤 |
| 9 | Key 安全 | Key 可能被顺手写进脚本 | `api.txt` 已进 `.gitignore`；`llm.resolve_key` 支持 env/文件/界面三选一，无 Key 自动离线 |
| 10 | 编码 | 中文在 GBK 终端乱码 | `selftest.py`/`verify.py` 强制 UTF-8 输出；界面不受影响 |

**验证方式**：把 `SS_OUT` 指到新目录重跑 01→03→06，产物与本机逐字节一致（仅 `meta.generated_at` 时间戳不同）。

## 6. 常见错误对照

| 报错 | 原因 | 处理 |
|---|---|---|
| `pip-unpack-xxx 找不到` | 工程路径含中文，pip 解包目录乱码 | `bootstrap.ps1` 已把 TEMP 指到 `.tmp`；仍失败就把工程放到 `D:\AIComp` |
| `[WinError 5] 拒绝访问 C:\Users\...\.streamlit` | Streamlit 要写用户目录 | 用 `ui\run.bat`（自动重定向） |
| `ModuleNotFoundError: streamlit` | 用了系统 Python | 用 `.venv-ui\Scripts\python.exe` |
| `process() takes no keyword arguments` | 解释器/`openai` 版本不匹配（如 Python 3.7 环境） | 统一用 `.venv-ui`（Python 3.13 + openai 3.51） |
| `401 Authentication Fails` | Key 错、或 `--api-key a b` 多传了一个值 | 只传一个值，或用环境变量 `DEEPSEEK_API_KEY` |
| 控制台中文乱码 | GBK 终端 | `chcp 65001`，或忽略（浏览器不受影响） |
| 04 报缺 chromadb | 未装可选依赖 | `pip install -r requirements-rag.txt`，或 `run_all.ps1` 默认跳过 |
