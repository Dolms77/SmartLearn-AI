# 复现手册（交给队友 / 其他同学）

> 目标：换一台 Windows 电脑，**不解压任何额外东西、不改一行代码**，30 分钟内跑出与本机一致的产物和界面。
> 本文档只讲"给什么、怎么跑、跑不对怎么办"；方案本身见 `方案设计/技术方案与实施指引.md`。

## 1. 队友拿到后 3 步跑通

```powershell
# ① 首次使用时准备环境（自动建 .venv-ui + 装依赖 + 自检）
.\scripts\bootstrap.ps1

# ② 日常运行入口：2 号 bat 执行分析脚本、校验产物
.\2_一键运行全部.bat

# ③ 启动 Streamlit 界面
.\3_启动界面.bat
```

预期：2 号 bat 最后打印 `[OK] 产物齐全且关键数字一致`；浏览器打开 `http://localhost:8501`。默认流程包含 05 知识图谱与 06 学情仪表盘，跳过可选 04；运行后在已打开的界面点击 **Rerun**，UI 会重新读取更新的 JSON。

> **本地模型（推荐，只做一次）**：界面默认走本机 Ollama。执行 `ollama pull deepseek-r1:8b`（约 5.2 GB）并保持 Ollama 运行，侧栏会显示「🟢 本地模型已就绪」；不装也能用，只是问答退回离线模板（见 §1.4）。

## 1.1 使用已有 Python 环境

如果已经有可用的 Python 虚拟环境，先在终端激活它，再运行：

```powershell
python -m pip install -r requirements.txt
.\scripts\run_all.ps1 -Python (Get-Command python).Source
```

等效地，也可通过 `2_一键运行全部.bat -Python <python.exe完整路径>` 指定解释器。不要在完整流程后重复手动运行 08；pipeline 已包含任务三生成。

### 脚本依赖

Python 3.10 或更新版本即可。01、02、07、08、09 以及 03 的规则诊断只用标准库；05 的知识图谱需要 `networkx`、`pyvis`；03 的 DeepSeek 深度诊断与界面云端模式可选安装 `openai`。这些基础依赖列在 `requirements.txt`。

04 是可选 RAG 模块，需要 `langchain`、`langchain-community`、`chromadb`、`sentence-transformers`。首次运行会下载 `BAAI/bge-small-zh-v1.5` embedding 模型（约 500 MB），并在本机生成向量库。

```powershell
# 在仓库根目录，先激活已有虚拟环境
$py = (Get-Command python).Source

# 仅在依赖缺失时安装；TUNA 清华 PyPI 镜像用于 Python 包
& $py -m pip install -i https://pypi.tuna.tsinghua.edu.cn/simple -r requirements-rag.txt

# 模型文件不是 PyPI 包；通过 HF Mirror 下载
$env:HF_ENDPOINT = "https://hf-mirror.com"
$env:HF_HUB_DISABLE_XET = "1"
$env:HF_HUB_DISABLE_TELEMETRY = "1"

# 需已有 output/cleaned_data.json，以及默认数据目录中的题目与材料.csv
& $py ".\已完成脚本\04_rag_knowledge.py"
```

清华 TUNA 提供的是 PyPI 包镜像，不托管 Hugging Face 模型文件；模型下载使用 [HF Mirror](https://hf-mirror.com/) 的 `HF_ENDPOINT`。首次下载后模型会缓存到本机，之后通常无需重复下载。生成物为 `output/chroma_db/` 和 `output/knowledge_base.json`。若要连同其余模块一起重跑，在设置好上述环境变量后运行 `.\scripts\run_all.ps1 -Python $py -WithRag`。

不运行 04 时无需安装 RAG 依赖。运行 03 的规则版也不需要 API Key；如要使用 DeepSeek，可在环境变量 `DEEPSEEK_API_KEY` 中配置，或通过 `--api-key` 参数传入。

默认数据和输出目录都根据脚本位置推导，不依赖当前工作目录或本机盘符。需要覆盖时可设置 `SS_DATA`、`SS_OUT`，或给 07/08 传 `--output-dir`。

## 1.4 模型配置（本地 Ollama 默认 / 云端 DeepSeek 可选）

界面默认走本机 Ollama，不需要 Key、不联网：

```powershell
ollama pull deepseek-r1:8b        # 约 5.2 GB；也可用 deepseek-r1:7b
ollama list                       # 确认模型在列表里
```

启动界面后，侧栏「⚙ 模型与数据」显示「🟢 本地模型已就绪：本地 · deepseek-r1:8b」即生效。模型名不用改代码，`llm.status()` 会按 `8b → 7b → 任意 deepseek-r1 → 第一个模型` 自动挑。

要用云端 DeepSeek 时，**先把后端切成 api**，再提供 Key：

```powershell
set SA_LLM_PROVIDER=api
set DEEPSEEK_API_KEY=sk-xxxx      # 或根目录 api.txt（已被 .gitignore 屏蔽）
```

> 界面侧栏的 Key 输入框只有在 `SA_LLM_PROVIDER=api` 时才生效；默认 ollama 后端下填了也不会调用云端。

可选：批量预生成 LLM 版错因诊断（173 条解答题）

```powershell
.venv-ui\Scripts\python.exe ui\llm_upgrade.py --limit 173 --sleep 0.3
```

本地模型约 11 分钟、免费；云端按 token 计费（约 ¥0.5–1、15–20 分钟）。不跑也能用，只是会少一块「规则 vs 本地模型」的复核对比。

## 1.5 在网页里上传自己的学情数据

欢迎页有两个按钮：左边「选择身份」直接用仓库自带的分析结果进入；右边「上传学情数据」展开上传面板，分析完成后自动切到新结果。

上传流程：

1. 下载 CSV 模板，按表头填 5 个文件（`课程要求.csv`、`题目与材料.csv`、`模拟学生.csv`、`测验节点.csv`、`作答记录.csv`），打包 zip 或逐个上传；
2. 校验通过后勾选要跑的脚本，点「开始分析」；进度面板每秒刷新，完成后点「进入智能体」（或面板里的「使用」）；

要点：

- 每个脚本都可以单独开关；**缺依赖的步骤会置灰**（04 需 `langchain/chromadb/sentence-transformers`，05 需 `pyvis`），旁边写明缺少什么；
- 01/02/03/08/09 是界面必需步骤，取消会提示“相关页面缺数据”；
- 分析在**独立后台进程**里跑，进度每秒刷新，刷新/关页不会中断；单步预计耗时在勾选时显示，超过 1 分钟会提示“可以最小化窗口”；
- 运行目录默认在仓库 `runs/`（可用环境变量 `SA_RUNS_DIR` 改到可写位置），每次运行一个时间戳目录：`input/`、`output/`、`logs/`、`run.json`；
- 失败时页面直接展开失败步骤的日志尾部；「取消分析」会在当前步骤结束后停止。

## 1.6 前端组件（只有改样式才需要）

教师「班级概览」里的班级对比、错因 waffle、评分步骤列表是 React 组件，源码在 `ui/class_comparison/`，
构建产物 `ui/class_comparison/dist/` 已随仓库提交——**运行时不需要 Node，也不需要 `npm install`**。

只有修改了 JSX / CSS 或传给组件的数据格式时才需要重新构建：

```powershell
cd ui\class_comparison
npm ci
npm run build      # 生成 dist/，base=./ 供 Streamlit 组件加载
```

构建后把 `dist/` 一并提交（或重新打包），否则界面仍读旧产物。细节见 `ui/class_comparison/README.md`。

## 6. 常见错误对照

| 报错 | 原因 | 处理 |
|---|---|---|
| `pip-unpack-xxx 找不到` | 工程路径含中文，pip 解包目录乱码 | `bootstrap.ps1` 已把 TEMP 指到工程内 `.tmp`；仍失败时可将工程移到不含中文的目录 |
| `[WinError 5] 拒绝访问用户目录\.streamlit` | Streamlit 要写用户目录 | 用 `ui\run.bat`（自动重定向） |
| `ModuleNotFoundError: streamlit` | `.venv-ui` 依赖未安装完整；此前安装失败可能未中断流程 | 从仓库根目录重新运行 `1_一键安装.bat` |
| `process() takes no keyword arguments` | 解释器/`openai` 版本不匹配（如 Python 3.7 环境） | 统一用 `.venv-ui`（Python 3.13 + openai 3.51） |
| `401 Authentication Fails` | Key 错、或 `--api-key a b` 多传了一个值 | 只传一个值，或用环境变量 `DEEPSEEK_API_KEY` |
| 控制台中文乱码 | GBK 终端 | `chcp 65001`，或忽略（浏览器不受影响） |
| 04 报缺 chromadb | 未装可选依赖 | `pip install -r requirements-rag.txt`，或 `run_all.ps1` 默认跳过 |
| 知识图谱一直在缓慢转动 | 力导向布局未收敛（旧版未冻结物理引擎） | 重跑 05 即可：新脚本在 400 次迭代后冻结物理；已有产物直接替换 `output/knowledge_graph.html` |
