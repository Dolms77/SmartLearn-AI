# 复现手册（交给队友 / 其他同学）

> 目标：换一台 Windows 电脑，**不解压任何额外东西、不改一行代码**，30 分钟内跑出与本机一致的产物和界面。
> 本文档只讲"给什么、怎么跑、跑不对怎么办"；方案本身见 `方案设计/技术方案与实施指引.md`。

---

## 0. 先划清共享边界（重要）

| 对象 | 能给什么 | 不能给什么 |
|---|---|---|
| **本队队友** | 全部代码 + 全部数据 + 全部产物 | —（队内共享不受限） |
| **其他参赛队 / 外校同学** | 代码、复现手册、字段说明、JSON Schema、界面截图 | **赛题原始数据**（`赛题材料/` 全目录，含 70 MB zip）与任何 `output/` 里的学情记录 |
| 任何人 | — | `api.txt`（含真实 Key）、任何真实学生信息 |

赛题原文："赛题组提供的课程标准、学情数据等资料仅限本次大赛使用，不得外传或用于其他用途，赛后须按赛题组要求删除。"
→ 所以外发版本请用 **§2 的"代码版"清单**，并在 README 顶部保留这句话。

## 1. 队友拿到后 3 步跑通

```powershell
# ① 首次使用时准备环境（自动建 .venv-ui + 装依赖 + 自检）
.\scripts\bootstrap.ps1

# ② 日常运行入口：2 号 bat 执行分析脚本、校验产物
.\2_一键运行全部.bat

# ③ 启动 Streamlit 界面
.\3_启动界面.bat
```

预期：2 号 bat 最后打印 `[OK] 产物齐全且关键数字一致`；浏览器打开 `http://localhost:8501`。默认流程保留 05 知识图谱，跳过可选 04 和独立仪表盘 06；运行后在已打开的界面点击 **Rerun**，UI 会重新读取更新的 JSON。

## 1.1 使用已有 Python 环境

如果已经有可用的 Python 虚拟环境，先在终端激活它，再运行：

```powershell
python -m pip install -r requirements.txt
.\scripts\run_all.ps1 -Python (Get-Command python).Source
```

等效地，也可通过 `2_一键运行全部.bat -Python <python.exe完整路径>` 指定解释器。不要在完整流程后重复手动运行 08；pipeline 已包含任务三生成。

### 脚本依赖

Python 3.10 或更新版本即可。01、02、06、07、08、09 以及 03 的规则诊断只用标准库；05 的知识图谱需要 `networkx`、`pyvis`；03 的 DeepSeek 深度诊断可选安装 `openai`。这些基础依赖列在 `requirements.txt`。

04 是可选 RAG 模块，需要 `langchain`、`langchain-community`、`chromadb`、`sentence-transformers`。首次运行会下载 `BAAI/bge-small-zh-v1.5` embedding 模型（约 500 MB），并在本机生成向量库。

```powershell
# 在仓库根目录，先激活已有虚拟环境
$py = (Get-Command python).Source

# 仅在依赖缺失时安装；TUNA 清华 PyPI 镜像用于 Python 包
& $py -m pip install -i https://pypi.tuna.tsinghua.edu.cn/simple -r requirements-rag.txt

# 模型文件不是 PyPI 包；通过 HF Mirror 下载
$env:HF_ENDPOINT = "https://hf-mirror.com"
$env:HF_HUB_DISABLE_XET = "1"
$env:HF_HUB_DISABLE_TELEMETRY = "1"

# 需已有 output/cleaned_data.json，以及默认数据目录中的题目与材料.csv
& $py ".\已完成脚本\04_rag_knowledge.py"
```

清华 TUNA 提供的是 PyPI 包镜像，不托管 Hugging Face 模型文件；模型下载使用 [HF Mirror](https://hf-mirror.com/) 的 `HF_ENDPOINT`。首次下载后模型会缓存到本机，之后通常无需重复下载。生成物为 `output/chroma_db/` 和 `output/knowledge_base.json`。若要连同其余模块一起重跑，在设置好上述环境变量后运行 `.\scripts\run_all.ps1 -Python $py -WithRag`。

不运行 04 时无需安装 RAG 依赖。运行 03 的规则版也不需要 API Key；如要使用 DeepSeek，可在环境变量 `DEEPSEEK_API_KEY` 中配置，或通过 `--api-key` 参数传入。

默认数据和输出目录都根据脚本位置推导，不依赖当前工作目录或本机盘符。需要覆盖时可设置 `SS_DATA`、`SS_OUT`，或给 07/08 传 `--output-dir`。

## 3. 为了让别人能跑，已经做了什么调整

| # | 调整 | 原来 | 现在 |
|---|---|---|---|
| 1 | **路径可移植** | 06 写死运行环境路径，07/08 默认依赖启动目录 | 01–09 默认按脚本目录定位；支持 `SS_DATA` / `SS_OUT` 环境变量覆盖 |
| 2 | 数据相对定位 | 写死赛题数据绝对路径 | 默认按工程相对位置推导，移动整个文件夹不影响 |
| 3 | 一键环境 | 手工 pip，中文路径会崩 | `bootstrap.ps1` 自动选 ≥3.10 解释器、把 `TEMP` 指到 ASCII 目录、装完即自检；也可用 `-Python` 复用已激活环境 |
| 4 | 一键执行 | 要按顺序手敲多条命令 | `run_all.ps1` 串行执行 01–05、07–09 + 计时 + 自动校验；04 可 `-WithRag` 选开，06 不自动生成 |
| 5 | 产物校验 | 无 | `verify.py`：8 个必产文件 + 8 项关键数字（含任务1主题/指标/题目映射） |
| 6 | 界面启动 | 直接 `streamlit run` 报 `WinError 5` 并卡在 `Email:` | `ui/run.bat` / `run.ps1` 自动重定向 `HOME` 到 `.streamlit-home` 并预写 `credentials.toml` |
| 7 | 依赖版本 | 只有口头清单 | `requirements.txt` 汇总 UI 与脚本依赖；版本范围兼容 Python 3.10+，安装失败会明确报错 |
| 8 | 缺依赖的降级 | 04/05 直接崩 | 05 缺 `pyvis`、04 缺 `chromadb` 时会打印"缺少依赖"并跳过，不影响其余步骤 |
| 9 | Key 安全 | Key 可能被顺手写进脚本 | `api.txt` 已进 `.gitignore`；`llm.resolve_key` 支持 env/文件/界面三选一，无 Key 自动离线 |
| 10 | 编码 | 中文在 GBK 终端乱码 | `selftest.py`/`verify.py` 强制 UTF-8 输出；界面不受影响 |

**验证方式**：把 `SS_OUT` 指到新目录重跑 `run_all.ps1`，再由 `verify.py` 校验核心数字与任务1结构。05 图谱需要 `pyvis`；若缺少该依赖，脚本会提示并跳过。

## 6. 常见错误对照

| 报错 | 原因 | 处理 |
|---|---|---|
| `pip-unpack-xxx 找不到` | 工程路径含中文，pip 解包目录乱码 | `bootstrap.ps1` 已把 TEMP 指到工程内 `.tmp`；仍失败时可将工程移到不含中文的目录 |
| `[WinError 5] 拒绝访问用户目录\.streamlit` | Streamlit 要写用户目录 | 用 `ui\run.bat`（自动重定向） |
| `ModuleNotFoundError: streamlit` | `.venv-ui` 依赖未安装完整；此前安装失败可能未中断流程 | 从仓库根目录重新运行 `1_一键安装.bat` |
| `process() takes no keyword arguments` | 解释器/`openai` 版本不匹配（如 Python 3.7 环境） | 统一用 `.venv-ui`（Python 3.13 + openai 3.51） |
| `401 Authentication Fails` | Key 错、或 `--api-key a b` 多传了一个值 | 只传一个值，或用环境变量 `DEEPSEEK_API_KEY` |
| 控制台中文乱码 | GBK 终端 | `chcp 65001`，或忽略（浏览器不受影响） |
| 04 报缺 chromadb | 未装可选依赖 | `pip install -r requirements-rag.txt`，或 `run_all.ps1` 默认跳过 |
