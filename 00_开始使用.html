一、从零跑起来（约 6 分钟）

1装环境（只做一次，约 3–5 分钟）

双击根目录的 1_一键安装.bat，或在 PowerShell 里执行：

# 自动建 .venv-ui、装依赖、跑自检；解释器自动探测
.\scripts\bootstrap.ps1
# 想指定解释器时再加： -Python "C:\Python313\python.exe"

2跑流水线（约 30 秒）

双击 2_一键运行全部.bat，或：

.\scripts\run_all.ps1            # 01–09（04 需向量库、05 需 pyvis，缺依赖自动跳过）

最后看到 [OK] 产物齐全且关键数字一致 就算成功。

3启动界面

双击 3_启动界面.bat，浏览器打开 http://localhost:8501。

4装本地模型（推荐，只做一次，约 5 分钟）

界面默认用本机 Ollama 推理。没装模型时侧栏会显示「🟠 模型未就绪」，问答退回离线模板——功能仍可用，但看不到模型改写。

ollama pull deepseek-r1:8b      # 约 5.2 GB；也可用 deepseek-r1:7b
ollama list                     # 确认在列表里，回界面刷新即可
界面共 11 页，入口是「选择身份 → 选身份 → 选账号」三步：
学生端 5 页：对话 · 智能体 · 我的学情 · 学习建议 · 知识与成果；
教师端 6 页：对话 · 智能体 · 班级概览 · 学生名单 · 数据质量 · 知识与成果。

一·5 上传自己的数据（可选）

欢迎页右侧新增了「上传学情数据」按钮：想用自带结果就点左边的「选择身份」，想分析自己的数据就点右边展开上传面板。

  1. 点「下载 CSV 模板」，按表头填 5 个文件：课程要求.csv、题目与材料.csv、模拟学生.csv、测验节点.csv、作答记录.csv；
  2. 打包成 zip（或逐个上传），系统会先校验文件与列名，不通过会明确提示；
  3. 勾选要跑的脚本：缺依赖的步骤会置灰（04 需要 langchain/chromadb，05 需要 pyvis），01/02/03/08/09 是界面必需；
  4. 点「开始分析」→ 进度面板显示每一步状态；分析在后台进程里跑，刷新页面不会中断；
  5. 完成后点「进入智能体」，所有页面读的就是这次分析的结果。

提示

运行目录默认在 runs/，每次运行一个时间戳子目录（input / output / logs / run.json）；可用环境变量 SA_RUNS_DIR 改到其他可写位置。

三、四条数据口径（答辩可直接引用）

① 证据门槛

某学生在某指标上的已评分记录 < 3 条 时，界面只显示「证据不足」，不判掌握/薄弱。 360 个"学生×指标"格子里只有 130 个达标（36%）。

② 整体掌握度

只用"可判定指标"计算；全无证据时显示 —，不做先验填充。 例如 D17 只有 4 条记录 → 显示"0/9 指标可判定"。

③ LLM 只解释、不判定

错因类型必须落在 C1–C6、指标必须在 9 个之内，否则整条丢弃； 与规则结果冲突时以规则为准。

④ 数据清洗留痕

8 条规则（得分越界、评分点矛盾、修订版本、待评分、未作答、节点越界、主题错标、答对判 0） 每条都给命中记录编号。

四、模型：本地 Ollama（默认）/ DeepSeek（可选）

① 本地模型（默认，推荐现场演示）

装好 Ollama 并拉取模型即可，不联网、不需要 Key、数据不出本机。侧栏出现「🟢 本地模型已就绪」说明生效。

ollama pull deepseek-r1:8b
ollama list                     # 看到 deepseek-r1:8b 即可

② 云端 DeepSeek（可选，需要 Key）

先把后端切成 api，再提供 Key（环境变量或根目录 api.txt 二选一）：

set SA_LLM_PROVIDER=api
set DEEPSEEK_API_KEY=sk-xxxx

注意

界面侧栏的 Key 输入框只有在 SA_LLM_PROVIDER=api 时才生效；默认 ollama 后端下填了也不会调用云端。 api.txt 不在本压缩包里，需要各自配置；不要截图、不要录进视频。

③ 批量预生成错因诊断（可选）

# 本地模型：免费，约 11 分钟（173 条）
.venv-ui\Scripts\python.exe ui\llm_upgrade.py --limit 173 --sleep 0.3
# 云端模型：按 token 计费，约 ¥0.5–1、15–20 分钟

没跑这一步也能用：智能体页的「规则 vs 本地模型」对比会留空，其余功能不受影响。
