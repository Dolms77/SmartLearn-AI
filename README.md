# 智慧学伴 · 学情诊断与个性化学习智能体

第二届北京市大学生"人工智能+"创新大赛 · 北京数据集团赛题

> 赛题数据（课标、学情记录等）仅限本次大赛使用，不得外传或用于其他用途，赛后须按要求删除。

## 第一次用？直接打开 [00_开始使用.html](00_开始使用.html)

## 30 秒跑起来

```powershell
.\scripts\bootstrap.ps1                                     # 首次使用：建环境、装依赖、自检
.\2_一键运行全部.bat                                         # 默认执行 01–09（04 需向量库，缺依赖自动跳过）
.\3_启动界面.bat                                              # 启动界面 http://localhost:8501
```

详细说明、文件清单、常见错误：**[docs/复现手册.md](docs/复现手册.md)**
技术方案（含创新点、评分对齐、答辩预案）：**[docs/技术文档.md](docs/技术文档.md)**
界面与智能体流程的验证记录：**[docs/界面验证记录.md](docs/界面验证记录.md)**

一键流程已包含 05 知识图谱与 06 学情仪表盘；当前 Streamlit 界面直接展示 `output/` 中的作答过程、评分点、质量标记及班级统计。重跑脚本后，在界面点击 **Rerun** 即可重新读取更新后的 JSON。

## 数据入口

界面第一屏是**数据入口**：可以直接进入仓库自带的分析结果，也可以上传 5 个固定模板 CSV（模板可下载），勾选要跑的脚本后由后台进程分析，完成后进入智能体。每个脚本可单独开关，缺依赖的步骤（04 RAG / 05 图谱）会自动置灰并提示安装命令；运行目录在 `runs/`（可用 `SA_RUNS_DIR` 覆盖）。

## 三条口径（代码里写死，答辩可直接讲）

1. 指标证据 < 3 条 → 只输出「证据不足」，不判掌握/薄弱；
2. 整体掌握度只用"可判定指标"计算，全无证据时显示 `—`；
3. LLM 输出必须可映射到 C1–C6 且指标在 9 个之内，否则整条丢弃，以规则结果为准。

## 环境

Python ≥ 3.10；运行时依赖（界面 + 脚本）见 `requirements.txt`，RAG 可选依赖见 `requirements-rag.txt`，打包 exe 见 `requirements-build.txt`。界面默认用本机 Ollama（`ollama pull deepseek-r1:8b`），不装也能跑，只是问答退回离线模板。
